# Muqadas Ibrar — Portfolio

Personal portfolio for **Muqadas Ibrar**, Computer Science student and software engineer.

Visual language follows the approved Framora-style reference. Content, name, and contact are hers. Product requirements: [docs/PRD.md](docs/PRD.md).

## Run locally

Node.js 18+ is required.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Live site

GitHub Pages: [https://muqadas19.github.io/muqadas-portfolio/](https://muqadas19.github.io/muqadas-portfolio/)


## Stack

Next.js App Router, TypeScript, Tailwind CSS.
